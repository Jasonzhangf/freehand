## Error Mainline

- missing file or missing required snippet surfaces as gate failure
- mismatched mainline manifest path, generated wiki path, function map, test design, or feature map link surfaces as gate failure
- missing source file or missing source symbol in a migrated `bound` call-table row surfaces as gate failure
- duplicate feature-map seed entries for one `feature_id` surface as gate failure
- resource-map parse errors, missing required core resources, duplicate owners, missing projections, unregistered direct resource edges, missing source-edge registry rows, forbidden/direct relation conflicts, forbidden relations without matching indirect relation rules, no-op source shortcut gates, and deferred source gates surface as gate failures
- OpenMinis checkout/CI pin drift, missing pinned source path/symbol, lifecycle/phase drift, BrowserUse/Cookie/Profile/Takeover scope entry, machine/human topology registry drift, unbound target/mainline/resource-operation rows, evidence artifact identity drift, remaining legacy identity, or legacy online touch surfaces as gate failure
- missing `mainlines check`, launchd guard targets, a real macOS launchd job, or release dependency wiring in `make ci` / CI/CD surfaces as gate failure
- missing launchd runtime-home workdir initialization or a repository-root default surfaces as gate failure
- missing launchd Worker provider credential env propagation surfaces as gate
  failure before Worker services can be claimed provider-ready
- missing source-only search exclusions, missing unsafe-argument guards, or missing `scripts/source-search.sh` policy snippets surface as gate failure
- missing release prerequisites such as Java or Cargo surface as script failure before artifacts are claimed
- missing fixed-port daemon health, Chrome/CDP availability, WebUI browser failures, or ADP mismatch surface as online verification failure before alpha success is claimed
- missing mobile UI tree evidence summaries, failed required checks, or unrestored S-profile config/env surface as mobile UI tree audit failure; a locked/unavailable Android device is reported as blocked rather than completion
- launchd bootstrap, kickstart, or env-backed health endpoint failure surfaces as script failure before background service success is claimed
- macOS protected-folder permission denial surfaces as launchd install/restart preflight failure before the service is claimed healthy; `FREEHAND_FILE_PERMISSION_PREFLIGHT=warn` is an explicit operator override, not the default
- mismatched launchd daemon binary prefix surfaces as install script failure before service success is claimed
- symlink install failure surfaces before launchd symlink service success is claimed
- request-node structs that introduce metadata/debug/cache/control payload fields or types surface as gate failure
- ad hoc metadata owner types outside `freehand-metadata` or metadata owner structs that introduce request or control payload fields surface as gate failure
- invalid JSON mainline source surfaces as generation/check failure
- stale generated wiki surfaces as explicit freshness failure
- missing or stale ADP protocol manifest/constructor artifacts surface as gate failure with the exact exporter command to rerun
- no fallback path exists
- loop overreach, missing owner mapping, active kill switch, or exhausted budget surfaces as escalation/no-op instead of automated action

## Shared Multi-Reference Functions

- `verify_openminis_ui_migration_manifest_value` is the single migration-registry validator used by the repository gate and focused positive/negative manifest tests.
- `verify_openminis_ui_migration_node` is the non-recursive node evidence verifier: it validates a source-bound projection and never consumes online evidence or legacy-retirement attestations.
- `verify_openminis_ui_lifecycle_fields` and `verify_openminis_ui_manifest_phase` own per-node and aggregate lifecycle admission.
- `verify_openminis_ui_pinned_source`, `verify_openminis_ui_ci_checkout`, `verify_gate_workflow`, and `git_stdout` own deterministic pinned-source/workflow identity and source inventory proof.
- `verify_openminis_ui_tree_topology`, `parse_openminis_ui_mermaid_tree`, and `parse_openminis_ui_registered_paths` own exact human/machine entrypoint, edge, and return comparison.
- `verify_openminis_ui_node_operation_binding` owns promoted-node operation owner/endpoints/relation exactness, and `verify_openminis_ui_operation_contract` requires `contract_ready` and later nodes to exactly repeat the operation binding's owner-backed projection/query, generated command, and surface path. `verify_openminis_ui_target_bindings`, `verify_openminis_ui_resource_operation_bound`, and `declared_symbols` own source-bound target/mainline/resource-operation checks, including exact equality between the declaration's repository-relative file and the accepting mainline row's `file_path`. Rust uses `syn`, Swift uses `swiftc -frontend -dump-parse`, and JS/TS/Kotlin use their language tree-sitter grammars with syntax-error trees rejected before traversal, and local-scope JS/TS/Kotlin declarations rejected; lexical keyword scans are not declaration truth.
- Active module-level const/static, impl/trait associated const, enum discriminant, and block-local const/static initializers have deterministic owner-qualified caller identities; inactive cfg initializers fail closed. Block-level imports and value bindings enter lexical scope only in their active cfg projection. Parsed external `Deref` implementations bind repository-local associated `Target` types for local method dispatch without inventing target edges for unrelated external-trait methods.
- `verify_openminis_ui_evidence`, `verify_openminis_ui_evidence_worktree`, and `read_openminis_ui_evidence_artifact` own structured online artifact identity, exact node/migration-unit identity, exact pre-promotion source revision, field-normalized canonical-manifest lifecycle transition admission, source/registry/verifier/manifest-contract dirty-path rejection, and exact gate coverage.
- Transparent parenthesized/grouped direct callees are unwrapped before path resolution, so `(target)()` and `target()` register the same direct edge.
- `verify_openminis_ui_legacy_retirement` owns physical disappearance and dedicated online no-touch proof.
- `verify_openminis_ui_map_documents` and `verify_openminis_ui_map_path` own canonical map location, aligned feature sets, owner inclusion, and document self identity for every lifecycle state.
- `discover_rust_call_graph` owns parsed, module-qualified call truth without a name whitelist. Production and test cfg projections are discovered independently and merged as production plus test-only truth; disabled modules, statements, expressions, match arms, block imports/value bindings, and initializers add no edge. `call_graph/discovery/scope.rs` owns exact aliases, lexical globs, qualified paths, callable-local associated paths, lexical shadow precedence, and re-export resolution with ambiguity rejection. `FunctionCallVisitor` stays owned by `visitor.rs`; `visitor/entry.rs` owns callable and initializer traversal, including associated-initializer `Self` ownership, while `visitor/assignment.rs` owns receiver-state replacement. `methods.rs` owns receiver/trait dispatch, inherited defaults, smart-pointer autoderef, built-in container inference, associated initializers, and enum discriminant initializer identities; `methods/local_items.rs` cfg-filters every function-local item before indexing, preserves its synthetic declaration identity, gives active block-local const/static initializers independent callable-scoped identities, resolves method bodies against the real enclosing Rust module, and rejects active impl/trait declarations nested below the callable body until a stable nested identity exists. Callable parameters, callable-local declarations, and local values shadow same-named module functions/types; destructured and conditional bindings replace outer receiver/iterable truth in lexical scope. External chains remain external, unresolved potentially local calls fail closed, qualified UFCS and unexpandable nested code are rejected, and test identity comes only from parsed attributes/ancestor projections. Migration-owned callees retain legitimate non-test inbound callers; external callees retain only migration-owned direct callers. The current machine registry contains 69 total shared functions, 68 migration-owned shared functions, and 300 exact production direct-call edges.

## Legacy Scan-Root Registry

- `MainlineCallDoc.legacy_scan_roots` is the machine registry. A node may be registered only in a canonical self-identifying `docs/mainline-calls/*.json` mainline whose `feature_id` equals the node `owner_feature_id`.
- `verify_owner_bound_legacy_scan_roots` requires exactly one row for the retiring node, exact owner, `scan_paths`, `removed_paths`, `removed_symbols`, `removed_import_tokens`, and `removed_callers` equality with the manifest, existing repository-relative directory roots, and coverage of every bound `target_path` and registered `removed_path`.
- The manifest cannot choose an arbitrary repository-local empty directory. Missing, duplicate, touched-feature-owned, wrong-owner, path-drift, and uncovered target/removed path registries are hard failures.
