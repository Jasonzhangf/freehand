Config Contract

配置页面树与边界

Provider / 模型组

Provider 配置单独管理 registry、endpoint、auth、protocol、capability test；切换和策略单独管理 primary/fallback、模型组和路由，不混在同一扁平列表。

记忆位置

产品记忆在 daemon runtime home：session/turn truth 与 session-history。手机只展示和触发管理命令，不保存原始记忆真源。

Skill 位置

Freehand 当前真源是 `~/.freehand/skills` 和项目 `.agents/skills`，编译到 instruction capability manifest 后进入模型上下文。

兼容 Codex

Codex / 其他全局 skills 只能作为显式兼容导入源审计，默认不直接扫描。导入后必须进入 Freehand manifest 才能暴露给模型。

手机壳边界

不做手机本地文件系统配置。Android 只处理连接、通知、APK 更新和必要权限申请。

观测边界

Diagnostics 是独立一级入口，点开后才显示日志列表；不放进 provider settings，也不替代 session / worker 生命周期可观察状态。

Memory Truth

记忆在哪里

Daemon 侧：`~/.freehand/state/turns/<agent>/<session>/session-history.json` 及 turn/session truth。手机只读投影，不保存原片段。

Skill Truth

Skills 在哪里

Freehand 全局：`~/.freehand/skills`。项目局部：`<project>/.agents/skills`。编译结果：`~/.freehand/state/instructions/capability-manifest.json`。

Compat Import

Codex 兼容策略

`~/.codex/skills`、`~/.agents/skills` 等外部来源只作为显式导入候选。导入要生成 Freehand manifest 记录和错误报告。
