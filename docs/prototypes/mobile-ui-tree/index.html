Step 1

静态 UI Tree

Root Mobile Shell / Home 首页为 active sessions monitor + Master history
A · 左上

配置入口

进入所有低频系统配置，不承载当前任务状态。

  • Provider / 模型组
  • Daemon / 远程连接
  • Worker 数量与能力
  • Android 更新与权限状态
  • 查看配置入口审计
B · 右上前

定时任务

查看和创建 timer，不混进 task 或 debug。

  • 相对时间 timer
  • 绝对时间 timer
  • Cron / 循环 / 跳过规则
  • 到期唤醒提示词
C · 右上后

内置工具

展示可用工具入口和说明，不显示任务执行流水。

  • Select
  • Shell terminal
  • Daemon workspace tools
  • Open browser / Browser settings
D · 左下

New Conversation

只负责创建持久化用户会话。

  • 新建普通 session
  • 新建 task session
  • 选择工作目录
  • 保留当前草稿
E · 右下

Session Search

只搜索已持久化 session 内容，不创建新会话。

  • 全文搜索
  • 按 session / 时间筛选
  • 结果跳转到对应 turn
  • 不显示临时 worker 为顶层结果

一级内容只显示后台活动监控和 Master 历史 session 列表。

  • 活动 session 列表
  • Master 历史 session 列表
  • 不在首页一级展示 worker session 内容
  • 不重复显示 Timer / New 入口

Step 2

UI 要做的事情

入口边界

每个角只做一类事：配置、定时、工具、新建、搜索互不混用。

会话边界

首页一级列表只显示持久化 session；worker 临时会话不作为首页 session 内容展示。

状态边界

当前 session dashboard 只给总览；进入 session 后再看 turn、worker、retry、error。

下一步

这张 tree 过审后，再按入口逐个列 gap 和流程，不在本原型里偷偷接功能。

Step 3

局部入口审计

Design Lock

主界面锁定为四角图标入口 + 首页两块内容：活动 sessions 监控和 Master 历史 session 列表。首页一级列表禁止显示 worker session、Timer dashboard、New session 重复入口；worker 关系只在进入所属 session 后展开。

A · Config

配置入口

页面树
Provider configuration -> Provider switching / strategy -> Diagnostics -> Daemon / 远程连接 -> Worker 能力 -> Android 更新与权限。
职责
管理低频系统配置和能力声明，配置变更给出重启或测试入口。
禁止
不显示当前任务流水，不混入 session 搜索，不替代实时 dashboard。
Gap
需要把 provider test、升级检查、权限状态整理成同一配置树，但各自保留 owner。
B · Timer

定时任务入口

页面树
Timer list -> Create relative -> Create absolute -> Cron / recurrence -> Fired history。
职责
只管理 timer 本身：触发时间、本地时区、循环次数、唤醒提示词、到期记录。
禁止
不把 timer 当 task，不显示 worker 执行明细，不作为 debug 面板。
Gap
需要后续核对 timer 持久化、过期处理、重启后补触发和 UI 可见状态。
C · Tools

内置工具入口

页面树
Tool catalog -> Shell terminal -> Daemon workspace tools -> Browser -> Tool guide examples。
职责
展示工具能力、权限边界、最小示例和可手动打开的工具面。
禁止
不渲染某个 session 的工具执行 turn，不吞工具错误，不用统计 debug 代替工具证据。
Gap
需要把工具 schema、绝对路径/软链接规则、失败样本解释整理成可读工具指南。
D · New

新建入口

页面树
New conversation -> New task session -> Workspace directory -> Attachments -> Create draft。
职责
创建持久化用户 session 或 task session，并锁定工作目录、草稿和当前提交元数据。
禁止
不创建 worker 临时 session 作为顶层会话，不丢草稿，不用失败回执清空页面。
Gap
需要确认 new task 与普通 new session 的文案差异、cwd 必填规则和图片选择池入口。
E · Search

搜索入口

页面树
Query input -> Session filters -> Result list -> Jump to turn -> Restore context。
职责
搜索已持久化 session 内容，并跳转到对应 session / turn。
禁止
不创建 session，不把 worker 临时会话作为顶层结果，不搜索未持久化 transient debug。
Gap
需要定义搜索索引来源、worker 子结果如何挂回 parent session、结果跳转后的返回路径。
